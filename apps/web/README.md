# ReaderX Web

ReaderX 前端应用，基于 Next.js (App Router) + React 19 + shadcn/ui。

> 包管理：pnpm

## 开发

```bash
pnpm dev
```

浏览器访问 [http://localhost:3000](http://localhost:3000)。

## 构建

```bash
pnpm build
```

## 其他命令

```bash
pnpm typecheck       # 类型检查
pnpm lint            # Lint
pnpm format          # 格式化代码
```
