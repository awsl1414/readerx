# ReaderX Wireframes — 线框图

> 本文档定义每个页面的布局结构和视觉权重。页面结构见 [IA](./ia.md)，用户流程见 [User Flow](./user-flow.md)，视觉令牌见 [Design Tokens](./design-tokens.yaml)。

## 1. 设计原则

### 信息密度

不均匀但稳定。面积 = 重要性，滚动 = 降低优先级。

**视觉权重**：

```
权重 5（最强）— 继续阅读 Hero
  封面 + 标题 + 进度条 + 一键进入
  这是书架存在的核心意义

权重 3 — 书籍网格
  小封面 + 书名 + 进度
  功能：快速浏览和选择

权重 2 — 分组标签
  Chips，单行，可交互

权重 1（最弱）— 底部引导
  更低的对比度
  功能：引导到其他页面
```

### 间距规则

严格一致：
- 卡片间距：12px
- Section 间距：28px
- 内容 padding：24px（桌面）/ 16px（移动）
- 阅读器留白：40px / spacing.10（桌面）/ 20px / spacing.5（移动）

### 禁止

- 所有卡片等大的网格
- 所有文字等大的列表
- 无主次之分的 dashboard
- 每个区域相同 padding
- 实线边框（用 Surface 明度区分层级）

+------------------------------------------+

**交互**：
- 点击书籍封面 → 阅读器
- 长按书籍 → 操作菜单（删除/移入分组/查看详情/换源）
- 下拉刷新 → 检查书籍更新
- 排序选择 → 最近阅读/添加时间/书名/手动拖拽
- 视图切换 → 网格/列表

## 3. 搜索页 — `/search`

```
+------------------------------------------+
| ←  🔍 输入书名或作者...       书源选择▼  |  ← 搜索框 + 书源过滤
+------------------------------------------+

+------------------------------------------+
| 搜索历史                                  |
| [斗破苍穹] [诡秘之主] [剑来]             |  ← Chips，点击直接搜索
+------------------------------------------+

─────────────── 搜索结果 ──────────────────

+------------------------------------------+
| 搜索中... 书源A ✓ 书源B ✓ 书源C ⏳      |  ← 书源状态
+------------------------------------------+
| +--------------------------------------+ |
| | [封面]  斗破苍穹 · 天蚕土豆          | |
| |         来源: 书源A / 书源B           | |
| |         最新章: 第1642章              | |
| +--------------------------------------+ |
| +--------------------------------------+ |
| | [封面]  斗破苍穹前传 · 天蚕土豆      | |
| |         来源: 书源A                   | |
| |         最新章: 第320章               | |
| +--------------------------------------+ |
+------------------------------------------+
| 1 个书源无响应                            |  ← 底部汇总
+------------------------------------------+
```

**交互**：
- 输入 debounce 300ms，Enter 触发搜索
- 结果流式展示：stagger fade-in（每个 30ms）
- 同名书去重：显示多来源标记
- 点击结果 → 书籍详情页

## 5. 阅读器 — `/reader/[bookId]`

```
+------------------------------------------+
| ← 返回  第十二章 标题         ···         |  ← 顶栏（控制层，3s淡出）
+------------------------------------------+

                                            ← 全屏沉浸
         阅读内容区域                        ← 无导航、无侧边栏
         无边框、无装饰                      ← Surface 0 背景
         段落行距 ≥ 1.8em
         左右留白 ≥ 20px(移动) / 40px(桌面)

         段落一...
         段落二...
         段落三...

         ...章节末尾...
         ─── 章节完 ───
         [下一章: 第十三章 标题]

+------------------------------------------+
| 上一章    65% · 3/12页        下一章      |  ← 底栏（控制层，3s淡出）
+------------------------------------------+
```

**控制层**：点击屏幕中心浮出，3 秒无操作淡出。

**设置面板**（从控制层菜单打开）：
```
+------------------------------------------+
| 阅读设置                                  |
+------------------------------------------+
| 字号      [-]  16px  [+]                 |
| 行距      [-]  1.8em [+]                 |
| 翻页模式  [滚动] [分页]                   |
| 主题      ● ○ ○ ○ ○                      |  ← 5 套阅读器主题
+------------------------------------------+
```

**目录面板**（从控制层菜单打开）：
```
+------------------------------------------+
| 🔍 搜索章节...                            |
+------------------------------------------+
| 第一章 ...                                |
| 第二章 ...                                |
| ...                                       |
| 第十二章 ...          ← 当前              |
| ...                                       |
+------------------------------------------+
```

**选中文字菜单**：
```
          ┌──────────────────────┐
          │ 复制 | 高亮 | 搜索   │  ← 浮出菜单，紧贴选中区域
          └──────────────────────┘
```
